# ALIVE

A premium, calm way to let someone know you're okay — once a day, one
button.

This repository is the mobile app, built with Expo, React Native, and
TypeScript. See [ARCHITECTURE.md](./ARCHITECTURE.md) for how the
codebase is organized and why.

## Status

Foundation stage. The app currently runs entirely on local/demo state
— there is no backend, authentication, or real notifications yet. See
ARCHITECTURE.md for what's planned and what's intentionally not built
yet.

## Getting started

```bash
npm install
npm start
```

Then press `i` for iOS Simulator, `a` for Android emulator, or `w` for
web, or scan the QR code with Expo Go on your phone.

## Scripts

- `npm start` — start the Expo dev server
- `npm run ios` / `npm run android` / `npm run web` — start and open a
  specific platform
- `npm run typecheck` — run the TypeScript compiler with no output, to
  catch type errors
